### Overview

This project is a simple facebook scarping i made for learning scarping. 

### Installation

Install dependencies
```bash
pip -r requirements.txt
```

Install browser for playwright
```bash
playwright install
```

### How to use

Copy the **c_user** and **x_s** field on your browser cookies when login to facebook and paste it into **cookies.json** for using.
Remmeber to change the **user_agent** before running the script.
